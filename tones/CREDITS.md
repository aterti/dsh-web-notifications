# Bundled tone credits

## Generated in this repository

`chime.wav`, `ping.wav`, `bubble.wav`, `marimba.wav`, `knock.wav`, `alarm.wav`, and `triple-tick.wav` are synthesized by `tools/generate-tones.mjs` and committed so a fresh clone needs no audio toolchain. They are MIT, like the code.
